# SharedMediaAdditionalFonts

Inserts more than **40 additional fonts** into LibSharedMedia's storage.

LibSharedMedia is used in an estimated **~1,250+ addons** and downloaded over
**100 million times**.

LibSharedMedia is used as a library in _other_ addons to add resources such as
fonts, sounds, images, … By installing SharedMediaAdditionalFonts, you add fonts
to the list of fonts provided by LibSharedMedia to these addons. If your other
addons do not use LibSharedMedia, this addon (SharedMediaAdditionalFonts)
doesn't do anything.

Some popular addons that use LibSharedMedia:

- Recount / Skada Damage Meter / Details! Damage Meter
- Prat
- WeakAuras
- Omen Threat Meter
- Quartz
- …
